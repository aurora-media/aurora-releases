Aurora is free software you run on your own machine. This website presents it; downloads are published on GitHub.

Software, not media

Aurora is a self-hosted media server for files and sources you are entitled to access. Screenshots illustrate the interface and do not represent media included with the software.

Availability and pricing

Features and supported devices may change between releases. Aurora is free, and this website does not take payments, create subscriptions or issue licence keys.

Nothing is sold on this website. Any voluntary donation is made through a third-party platform under that platform's own terms.

Licence

The Aurora application is proprietary software. Its source code is private. The public repository contains the website, the installation documentation and the application downloads.

Hardware and compatibility

Playback depends on the file, browser and server hardware. Direct play and remux preserve the original video when the client supports it. Software transcoding of large HEVC files can exceed the capacity of a Raspberry Pi.

Questions

Use the public project tracker for general product questions. Do not post passwords, API keys, licence keys or other private information there.
